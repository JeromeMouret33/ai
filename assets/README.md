# Assets de référence

Déposer ici les assets de marque (ne pas committer de fichiers lourds/sensibles
sans raison — préférer Supabase `references` en prod) :

- `showroom-plaque.*`  — plaque showroom de référence (mur propre, sans logo).
- `logo-goodcar.*`     — logo GOODCAR HD (poussé en référence à chaque génération).
- `plaque-immat.*`     — image de plaque d'immatriculation GOODCAR (option plaque).

La bibliothèque de références (app) permet d'en ajouter plusieurs par type et de
choisir l'asset actif.
